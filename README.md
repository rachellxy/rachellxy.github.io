# rachellxy.github.io

Personal homepage of Xinyu Li, built with Jekyll on the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme, adapted from [zhangce01.github.io](https://github.com/zhangce01/zhangce01.github.io).

- `_config.yml`: name, affiliation, links, avatar
- `index.md`: About Me, Research Interests, News, Experiences
- `_data/publications.yml`: selected publications
- `blog/2026/hermes.html`: HERMES project page (standalone HTML)

Local preview: `bundle install && bundle exec jekyll serve`.
